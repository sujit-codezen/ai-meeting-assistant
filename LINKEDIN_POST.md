🚀 Excited to share my latest project: **AI Meeting Assistant** — an AI-powered meeting intelligence platform!

I built this to solve a real problem: meetings generate valuable insights, but they're lost in recordings and notes. This platform transforms conversations into **actionable business information** automatically.

**What it does:**

🎙️ Upload meeting recordings (MP3, WAV, M4A, MP4)
📝 AI transcribes speech to text with speaker identification
🧠 AI analyzes and extracts:
   → Executive summaries
   → Action items with owners & deadlines
   → Key decisions made
   → Sentiment analysis
🔍 Semantic search across all your meetings
💬 Ask questions about past meetings using AI

**Tech Stack I used:**

Backend: Python, Django, Django REST Framework
Frontend: Next.js 16, React 19, Tailwind CSS
Database: PostgreSQL, Redis, ChromaDB
AI/ML: faster-whisper (STT), Ollama + Llama 3.2 (LLM), sentence-transformers (embeddings)
Infrastructure: Docker, Celery, Docker Compose

**Key Learning:**

This project taught me how to build end-to-end AI pipelines — from audio processing to RAG-powered search. The most challenging part was integrating multiple AI components (transcription, LLM analysis, embeddings) into a seamless workflow.

**What's next:**

Adding real-time meeting transcription, calendar integration, and automated follow-up emails.

Check out the code: https://github.com/sujit-codezen/ai-meeting-assistant
